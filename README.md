# Student Performance Prediction using Machine Learning

## About Project
This project predicts students`
final marks using
Study Hours, Attendance, Previous
Marks and
Assignments Completed.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- joblib

## Machine Learning Algorithm
Linear Regression

## Project Features
- Data loading and cleaning
- Exploratory Data Analysis
- Correlation Heatmap
- Model Evaluation
- Student Marks Prediction
- Prediction History
- Data Visualization

## How to Run

1. Install required libraries:

    pip install -r requirements.txt

2. Train the model:

    python main.py

3. Predict student marks:

    python history.py

4. View prediction history:

    python history.py

5. Evaluate model:

    python evaluate.py

## Disclaimer
Predictions are estimates, not
guaranteed
actual examination results.
